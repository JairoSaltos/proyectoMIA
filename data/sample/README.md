# Datos seguros de demostración

Esta carpeta se reserva para ejemplos sintéticos o de prueba que no contengan
información personal, historias clínicas ni conversaciones reales.

La evidencia de demostración disponible actualmente es
[`CatClinic_MVP_Seguro/evidencia_guardrails.csv`](../../CatClinic_MVP_Seguro/evidencia_guardrails.csv).
Sus 13 filas registran casos técnicos usados para comprobar validaciones,
guardrails y presentación. No constituyen:

- un conjunto de entrenamiento o prueba del modelo;
- evidencia de uso real de la clínica;
- una validación con usuarios;
- una evaluación clínica;
- datos aptos para estimar métricas de exactitud.

Si se añade un archivo de ejemplo en el futuro, debe:

1. usar solo textos claramente sintéticos o casos ya aprobados para divulgación;
2. indicar su finalidad y procedencia;
3. evitar nombres, teléfonos, direcciones, identificaciones, correos, datos de
   pago y detalles clínicos identificables;
4. quedar marcado como demostración, nunca como dato real o de entrenamiento.

Los datos originales y sus condiciones de acceso se describen en
[`../raw/README.md`](../raw/README.md).
